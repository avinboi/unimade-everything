## What Unimade is
A student-life platform for hostel and PG students (Masters' Union, Gurugram first). Students book everyday services in one place; verified local partners do the work; Unimade keeps a cut. Not a laundry business: laundry is only the first service.

## 3. Deals and partners (free to Unimade now, paid later)
- **Restaurants near college: in-store discount.** The student shows their Unimade pass (WhatsApp message or app screen) at the counter for ~10–15% off. Tracked with a per-student code or a QR code at the counter. No delivery needed.
- **Packaged food brands: discount on the brand's own website.** Use **unique single-use codes**, not one public code. The brand gives a batch (e.g. 500); Unimade sends one per pass holder on WhatsApp. Reason: a public code like "UNIMADE15" leaks to coupon sites, non-students use it, the brand loses interest and the pass loses value. Brands usually pay 5–15% commission per sale made with a code.
  - **How the codes work, step by step (the owner found this confusing; explain it this simply when asked):**
    1. Unimade signs a deal with a food brand, e.g. a healthy-snacks brand.
    2. The brand creates a list of codes that each work only once, like UNI-7K2P, UNI-9XQ4, and so on, 500 of them. Brand websites (Shopify etc.) can generate these in a few clicks.
    3. When a student has an active Pass, Unimade sends that one student one code on WhatsApp.
    4. The student orders on the brand's website, types the code at checkout and gets 15% off. After that the code is dead, so if they post it online nobody else can use it.
    5. The brand sees how many of its codes were used, so it knows exactly how many sales Unimade brought. That's the proof Unimade uses to ask the brand for commission now and paid listings later.
    - Why not one shared code like "UNIMADE15": anyone could use it once it's posted online, so non-students get the discount, the brand can't tell which sales were really students, and the Pass stops being special.
- **Not doing:** Zomato/Swiggy codes (can't create or track them, earns nothing) and ordering food through the Unimade app (would mean building delivery and competing with Zomato).
- **Later, once there are a few hundred active users:** restaurants and brands pay to be listed or featured (v2 plan: ~₹20,000 per brand campaign, ₹1,499/month per featured listing).
